University IPv4 Addressing and VLSM Design

Project Overview

This project focuses on designing and implementing an efficient IPv4 addressing scheme for a university network using Variable Length Subnet Masking (VLSM). The network is designed and simulated using Cisco Packet Tracer.

Objectives

- Design a structured university network.
- Implement efficient IPv4 address allocation using VLSM.
- Minimize IP address wastage.
- Configure VLANs for departmental segmentation.
- Implement DHCP for automatic IP address assignment.
- Enable inter-VLAN communication.
- Verify network connectivity.

Network Requirements

The network is designed for the following departments:

Department| Required Hosts
CSE| 100
Data Science| 50
Cyber Security| 25
Administration| 15
Library| 10

Technologies and Concepts Used

- Cisco Packet Tracer
- IPv4 Addressing
- Variable Length Subnet Masking (VLSM)
- VLAN Configuration
- DHCP
- Inter-VLAN Routing
- Multilayer Switching

Network Implementation

The university network is designed using departmental switches connected to a multilayer core switch. VLANs are configured to separate departmental networks, while inter-VLAN routing enables communication between them. DHCP provides automatic IP address allocation to connected devices.

Project Files

- Packet Tracer: Network simulation file.
- Documentation: Project report in PDF format.
- Presentation: Project presentation in PowerPoint format.

Expected Outcome

The project demonstrates efficient IP address utilization, departmental network segmentation, automatic IP configuration and successful communication between different university departments.
